## About

This is the source code for my personal portfolio website — built with pure **HTML, CSS, and JavaScript**. No frameworks, no dependencies, just clean and fast code.

The site showcases my academic background, projects, awards, and experience as I prepare to begin my undergraduate studies in **Computational Science & Artificial Intelligence** at **LUT University, Finland**.

---

## Features

- ⚡ Pure HTML/CSS/JS — zero dependencies
- 🎨 Premium dark UI with custom animated cursor
- 🌀 Scroll-triggered reveal animations
- 📱 Fully responsive (mobile-friendly)
- 🔍 SEO optimized (meta tags, Open Graph)
- 📬 Working contact form via Formspree
- 📄 One-click CV download
